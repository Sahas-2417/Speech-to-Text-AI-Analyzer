# AI Speech-to-Text Transcriber with Sentiment & Summary Analysis

This project converts audio speech into text using AI-based transcription and performs sentiment analysis on the generated transcript. It also provides a short summary and downloadable transcript report.

## Features
- Upload audio files
- Convert speech to text
- Analyze transcript sentiment
- Generate short summary
- Download transcript
- Simple interactive dashboard

## Tech Stack
Python, Streamlit, Whisper, NLP, Sentiment Analysis
